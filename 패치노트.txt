#  v1.0.0  —  2026-06-13 (토)   "운영 개시"
##################################################################

  기일 일정 자동 알림 시스템 운영을 개시하였다. 직원이 Lawware에
  입력한 기일 일정을 매일 Discord 채널로 자동 발송한다.

  [NEW] 일정 자동 알림 최초 가동
        - Google Calendar(서비스계정·읽기전용)에서 하루치 일정을 읽어
          회사 표준 양식으로 변환 후 Discord 웹훅으로 전송.
  [NEW] 복수 캘린더 동시 지원
        - 캘린더 ID를 쉼표/공백으로 여러 개 입력 가능.
        - 구글 계정이 2개로 나뉘어 있어도 계정별 키(_2, _3…)로 모두 수집.
  [NEW] 회사 표준 출력 양식 확립
        - "YYMMDD 요일" 머리말 + "시간 [의뢰인] 기일종류 > 출석변호사" 한 줄 양식.
        - 정식 기일(사건번호+내용 보유)은 상세 양식, 그 외 일정은 제목 그대로.
        - 조사기일은 의뢰인 연락처까지 아랫줄에 표기.
        - 여러 캘린더에 겹쳐 들어온 동일 일정은 자동 중복 제거.
  [개선] 머리말 표기 정리
        - 시간 미지정(종일) 일정을 맨 위로 모아 배치.
        - 머리말 접두를 '#'에서 캘린더 표시(📅)로 변경.
  [NEW] 오후 '익일 송무팀별' 알림 추가
        - 오후에 내일 일정을 송무1/2/3팀 + 상담지원팀으로 분류해 따로 발송.
        - 팀별 메시지 사이는 보이지 않는 구분 문자(zero-width space)로 구분.

#  v1.1.0  —  2026-06-14 (일)   "발송 정시성 확보"
##################################################################

  알림 발송 지연 문제를 해소하기 위한 발송 체계 개편.

  [운영] 정시 발송 체계로 전환
        - 원인: GitHub Actions의 schedule cron은 정시 실행을 보장하지 않음
          (실제 07:00→08:11, 17:45→20:17 지연 발생).

          비활성화(주석 처리).
        - 결과: 실행 큐 혼잡과 무관하게 정시 발송, 지연 사실상 해소.
  [문서] 운영 문서 정비
        - '전체 구성도', '작업 기록', '외부 스케줄러 설정 가이드' 신설.
        - README에 docs 링크 연결.
  [운영] 로컬 실행 편의 개선
        - python-dotenv 도입 → 로컬 실행 시 .env 자동 로딩.

#  v1.4.0  —  2026-06-18 (목)   "비고 노출 · 선고 대리 표기 일원화"
##################################################################

  캘린더 '비고'란을 알림에 반영하고, 선고기일 대리출석 표기를 정리하였다.

  [NEW] '비고' 선별 노출
        - 비고 내용이 '장소' 또는 '제출/이행 여부'일 때만 아랫줄에
          원문 그대로(라벨 없이) 표시. 그 외(복대리·메모 등)는 표시하지 않음.
        - 제출 키워드(제출·접수·발송·납부·이행·체결·완료·미제출 등),
          장소 키워드(법원·검찰청·경찰서·법정·조정실 등)·전화번호로 판별.
          두 키워드가 함께 있으면 '제출'을 우선.
        - 장소성 비고는 기존 '장소' 줄을 대체하지 않고 함께 병기.
          (예: 경찰서 장소 + 비고의 검찰청 조정실을 나란히 노출)
        - 판별 키워드는 transform.py 의 BIGO_SUBMISSION_KW /
          BIGO_LOCATION_KW 표만 수정하면 운영 중 조정 가능.
  [개선] 선고기일 대리출석 표기 일원화
        - 선고기일에 한해 출석변호사의 '복대리·청취대리·선고청취대리·
          선고청취' 표기를 모두 '청취대리'로 통일.
        - 다른 기일종류(변론·공판 등)의 표기는 원문 그대로 유지.
  [문서] 회귀테스트 6건 추가(비고 분류·병기·선고 일원화), README 규칙 반영.

#  v1.5.0  —  2026-06-23 (화)   "상담·접견 양식 정비 · 비고 전면 노출"
##################################################################

  상담/미팅·접견 일정 표기를 정식 기일 수준으로 정비하고,
  비고는 전면 노출로 변경하였다.

  [개선] 상담/미팅([회의]) 표기 정리
        - '[회의] (구분) [의뢰인]내용' → '[의뢰인] 내용 > 담당변호사님' 으로 재구성.
          [회의]·(구분) 표기는 제거.
        - 장소(구분)와 의뢰인 전화('이름(전화)')를 아랫줄에 표기.
          전화는 '의뢰인연락처' 필드 우선, 없으면 설명 맨 윗줄의 번호 줄에서 인식.
  [NEW] 접견 장소 표기
        - 제목·설명에 '○○구치소'/'○○교도소' 이름이 있으면 그 기관을 장소로 표기
          (없으면 생략). 제목 괄호 '(서울남부교도소)'처럼 중복되면 괄호는 제거.
  [개선] 자사 사무소 장소 정규화
        - '구분' 값이 아스테리움·1006호·서울사무소 등이면 '서울 1006호',
          404호류면 '서울 404호', 학익동·인천 등이면 '인천사무소' 로 통일.
        - 별칭 추가/수정은 config/locations.yaml 에서 관리.
  [개선] 비고 노출 정책 변경  (v1.4.0의 '선별 노출'을 대체)
        - 선별 필터(장소/제출만) 폐지 → 비고에 내용이 있으면 전부 노출.
        - 표시: 모든 일정 맨 아랫줄에 '비고 : 원문' (장소·연락처 줄보다 아래).
          예) 상소제기 불변기일의 '비고: 항소X' → '비고 : 항소X'
        - ※ 비고 내용이 그대로 발송되므로, 민감정보·내부 메모는 비고에 기재 금지.
  [개선] 선고기일 '청취대리'는 '님' 없이 표기(출석방식 라벨이므로).
  [문서] README 변환 규칙·보안 주의 갱신, 회귀테스트 갱신(35건 통과).

  [NEW] 담당직원 소속팀 폴백 — 이돈호 변호사 단독 사건도 팀 알림에 포함
        - 담당변호사가 송무팀 명단 밖(예: 이돈호 대표변호사 단독)인 사건이라도,

          예: '[강성구] 스마트접견'(담당 이돈호, 직원 유은진)

        - 접견 일정 설명에 숫자만 적힌 줄('004627')이 있으면 접견번호로
          인식해 '접견번호 : 004627' 아랫줄을 붙인다. 라벨이 윗줄에만 있는
          '스마트접견번호' ↵ '000074' 형태도 인식.
        - 전화번호(하이픈 포함)·사건번호('key: value' 형식)는 오인하지 않는다.
        - 종전에는 캘린더에 '접견번호'라는 문구를 직접 기재해야만 표시되었다.

          ── 예시 ──────────────────────────────
          11:30 [강성구] 스마트접견 > 이돈호
                  접견번호 : 005260
          ──────────────────────────────────────
